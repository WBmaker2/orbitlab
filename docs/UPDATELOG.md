# OrbitLab 업데이트 내역

## 2026-10-27

### 검증과 자동 테스트 추가

- 미션·타임라인·화면 전환·레이어·교사 초기화·키보드 조작을 자동으로 확인하는 브라우저 테스트를 추가했습니다.
- 탐구, 미션, 지구 관측자, 교사 화면의 접근성을 자동 검사하도록 했습니다.
- 1440×900, 1024×768, 390×844 화면 크기에서 주요 화면 스크린샷을 남기도록 했습니다.
- 오프라인에서 다시 열어도 앱이 뜨는지, 첫 화면이 느린 4G에서 2.5초 안에 열리는지, 번들 크기가 예산 안인지 확인합니다.
- 시뮬레이션을 재생할 때 화면 갱신이 계속 돌아가는지도 확인합니다. 성능 테스트는 다른 테스트와 섞이지 않도록 따로 실행합니다.
- 외부 AI나 서버를 호출하지 않는지도 테스트로 확인합니다.

### 화면과 사용성 수정

- 앱을 처음 열면 한국 표준시(KST) 현재 날짜와 시간에서 시작하도록 했습니다.
- 타임라인에 `현재` 버튼을 추가해, 시간을 움직인 뒤에도 언제든 현재 시각으로 돌아올 수 있게 했습니다.
- 화면에 표시되는 시간 기준을 UTC에서 KST로 바꿨습니다. 내부 천문 계산은 UTC 기준을 유지합니다.
- 휴대폰에서 하단 탭(시간·레이어·설명)이 처음부터 비어 보이던 문제를 고쳤습니다.
- 넓은 화면에서 지구와 달이 양쪽 패널에 가려지던 카메라 구도를 조정해, 태양·지구·달이 한눈에 보이도록 했습니다.
- 미션 화면에서 지구 관측자 뷰로 전환한 뒤 미션 패널이 숨겨지던 문제를 고쳤습니다.
- 교사 모드에서 학생이 제출한 답안과 미션 상태가 바뀌지 않던 문제를 고쳤습니다.
- 레이어를 켜고 끌 때 "공전 궤도을"처럼 조사가 어색하게 읽히던 안내 문구를 바로잡았습니다.
- 미션 선택 버튼, 로고, 교사 진행 막대의 스크린리더 이름과 상태 정보를 정리했습니다.

### 문서와 개발 환경

- README에 실행 방법, 화면 구성, 테스트 방법, 모형의 한계를 정리했습니다.

- 스크립트 파일의 린트 오류와 경고를 정리했습니다.
